# UI 整体换装设计（网页端 + 手机端，功能零改动）

- 日期：2026-08-30
- 状态：已获用户逐节确认（网页端 5 节 + 手机端方案）
- 目标：用"一整套组件"替换管理站网页与 Android App 的 UI，风格清新（山水青绿风），**不改变、不影响任何现有功能**。

## 1. 目标与硬约束

### 1.1 目标

1. 管理站网页：保留全部业务逻辑与接口，UI 层整体换成一套**本地内置的轻量组件体系**，风格清新。
2. Android App：保留全部页面逻辑，资源层换成 **Material 3 清新主题**。
3. 两端共用同一套"山水青绿"视觉语言（青绿主色、湖蓝辅助、浅青灰背景、白卡片、大圆角、柔和阴影）。

### 1.2 硬约束（不可违反）

- **功能零改动**：所有 API、元素 id、事件名、数据库、同步/扫码/拍照/地图逻辑一律不动。
- **CSP 不变**：`script-src 'self'`、禁内联脚本、禁 CDN → 新资源必须全部本地内置（CSS、内联 SVG、无第三方 JS）。
- **离线/偏远环境**：不使用网络字体、不使用任何外部服务。
- **验收红线**：现有 Playwright 端到端套件（`test/frontend.e2e.js`）必须全部通过；标签打印页 40 枚/页排版不破版；手机端户外强光可读、状态语义色含义不变。
- **后端零改动**：`server.js`、`schema.js` 等不动；发布仅涉及 `public/` 与 Android 资源/布局。

## 2. 子项目一：管理站网页换肤

### 2.1 技术路线

- 保留 `public/app.js` 全部业务逻辑、事件监听、状态管理与 Leaflet 地图逻辑；`index.html` 所有元素 id 与 `data-*` 钩子原样保留。
- 新增单一自包含 CSS 组件库（原地重写 `public/styles.css`，CSS 变量驱动），组件 = 语义化 class：`btn`（主/次/幽灵/危险）、`card`、`chip`、`table`、`dialog`、`badge`、`tabs`、`toast`、`input` 等。
- `app.js` 仅做**等价的 class/内联样式替换**（不改任何判断逻辑）；`index.html` 仅换结构壳的 class。
- 图标：本地内联 SVG 图标集（水滴、山、瓶等线性手绘风），替代部分 emoji。
- 分页实施：每完成一个页面即跑 Playwright 回归，绿了再进下一个。

### 2.2 视觉规格（山水青绿风）

| 令牌 | 值 |
|---|---|
| 主色 primary | 青绿 `#0E9F8A` |
| 辅助 accent | 湖蓝 `#2E7CB8` |
| 背景 | 极浅青灰 `#F4F8F7` |
| 卡片 | 纯白、圆角 `12px`、柔和阴影 |
| 文字 | 深青墨 `#17343A` / 次要灰 |
| 状态语义色 | 待采样=琥珀、已采样=青绿、可疑=橙红、已通过=绿（沿用含义，换清新色值） |
| 字体 | 系统字体栈（不引网络字体） |

### 2.3 覆盖范围（全量换装）

登录页、整体布局（顶栏/侧栏/日期归档）、按钮与工具栏（含"!"信息点气泡）、卡片、表格（斑马纹+悬浮行+状态色圆点）、全部弹窗（统一头/内容/操作区）、筛选 chips、提示条与 Toast、状态徽章、表单控件、标签打印页（保留打印 CSS）、审核对比页、地图控件与图例、空状态 SVG 插图、项目/采样员/点位管理、导出与设置、诊断日志页。

### 2.4 涉及文件

- `public/index.html`（结构壳 class 替换）
- `public/styles.css`（原地重写为主题化组件库）
- `public/app.js`（渲染字符串/内联样式的等价 class 替换，逻辑不动）
- 可选新增：`public/icons.svg`（内联 SVG 图标集）
- 文档：`docs/DEVELOPMENT_SPEC_V1.md` 增补条目、`APPENDIX_L_SOURCE_SNAPSHOT.md` 重新生成

### 2.5 验证与交付

1. 本地起服务逐页检查 + `test/frontend.e2e.js` 全部通过（验收红线）；
2. 截图给用户过目确认；
3. 提交 + 打新版本号（建议 v1.3.0）+ 服务端部署包 + GitHub 发布。

## 3. 子项目二：Android App Material 3 换肤

### 3.1 技术路线

- **逻辑零改动**：所有 Activity/Service/同步/定位/扫码/拍照代码原样保留。
- 只改资源层：`res/values` 的 Material 3 主题（themes.xml / colors.xml / shapes）、各布局使用 Material 组件样式（`MaterialButton`、`MaterialCardView`、大圆角、水波纹、新字体层级）。
- 与网页端共用"山水青绿"配色（主色 `#0E9F8A`、辅助湖蓝、浅青灰背景）。
- 所有控件 `id` 原样保留 → 代码绑定零改动。

### 3.2 覆盖范围

主界面（顶栏/状态条/底部四 tab）、任务列表（日期分组行+任务卡片+筛选条）、任务执行页、地图页控件、拍照/扫码/上传/我的/登录页、全部弹窗与 Toast。

### 3.3 户外可用性

保持浅色主题 + 高对比度（现场强光可读）；状态语义色不变（待采样=琥珀、已采样=绿、进行中=蓝、已取消=灰），仅换更清新的色值；图标改简洁线性风。

### 3.4 验证与交付

1. 编译通过 + 同证书签名（可覆盖安装 1.2.7，数据不丢）；
2. 功能回归清单：任务列表显示/点日期联动地图/开始采样/扫码/拍照/上传/同步/激活逐项验证 + 用户现场测试；
3. 后端零改动；出新版本（建议 v1.3.0）并发布 GitHub。

## 4. 实施顺序

1. 子项目一（网页端）实施 → 验收 → 发布；
2. 子项目二（手机端）实施 → 验收 → 发布。

## 5. 非目标（明确不做）

- 不做框架迁移（不引入 Vue/React/Compose）；
- 不改任何 API、数据库结构、同步协议；
- 不做深色模式、多语言、动画特效等附加功能；
- 不重构业务代码。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 换肤破坏功能 | 分页实施 + Playwright 红线 + 用户逐页确认 |
| 打印页破版 | 保留专用打印 CSS，单独验证 40 枚/页 |
| 强光下新配色可读性 | 手机端高对比度浅色主题 + 现场实测 |
| 字体/图标不本地化导致 CSP 违规 | 全部本地内置，无 CDN/无网络字体 |
