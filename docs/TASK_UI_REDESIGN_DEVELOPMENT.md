# 安卓端任务页重构开发文档

## 1. 目标

将安卓端底部“任务”页改为日期任务的主从结构：

`下发日期任务 → 该日期下的具体采样点 → 既有采样点详情页`

左侧只显示服务器下发的日期任务，不显示年月日历；每个日期任务显示已采样和未采样数量。右侧显示选中日期任务下的采样点列表。点击采样点继续进入现有 `TaskActivity`，保留定位、轨迹、二维码、拍照、离线保存和后台同步流程。

## 2. 范围与兼容性

- 安卓端：替换 `ExpandableListView` 日期展开结构为双栏主从界面，手机竖屏下使用窄左栏和右侧采样点列表。
- 服务器端：增加任务计划时间字段、移动端修改计划时间接口，并在移动同步结果中补充设备名称。
- 不改变采样记录、轨迹、二维码校验、照片上传、审核和离线队列协议。
- 老数据库通过增量迁移自动补齐新字段；已有任务的计划时间为空时显示“未设置”。

## 3. 数据与接口设计

### 3.1 任务计划时间

在 `tasks` 表增加 `planned_time TEXT NOT NULL DEFAULT ''`，格式固定为 `HH:mm`。日期仍使用现有 `planned_date`，样品编号仍只按日期生成，不因修改时间重新编号。

管理员创建任务时可选传入 `plannedTime`；不传则保持空值。管理员改期接口保留原行为，同时接受可选 `plannedTime`。

新增移动端接口：

`POST /api/v1/mobile/tasks/:id/schedule`

请求体 `{ "plannedTime": "09:30" }`。接口只允许任务所属采样员修改；已提交采样记录或已取消任务拒绝修改；空字符串表示清除时间。服务端校验 `^([01]\\d|2[0-3]):[0-5]\\d$`，并写入审计日志。

### 3.2 设备名称

移动同步任务查询返回当前登录设备的 `device_name` 和 `device_id`，安卓端优先显示设备名称，空值时回退到本地设备型号。设备名称仍由激活接口写入，不改变激活流程。

## 4. 安卓端交互

- 点击底部“任务”进入任务页，默认选中最新日期。
- 左栏日期任务卡显示：日期、已采样数量、未采样数量。
- 点击左栏日期，右栏刷新该日期下的采样点卡片。
- 采样点卡片显示：样品编号、样品类型、计划日期/时间、状态、采样员、App 设备名称；点击整卡进入 `TaskActivity`。
- 计划时间使用时间选择器编辑，保存成功后立即更新本地任务并调用服务器接口；离线时先写入本地待同步队列，联网后重试。
- 不再显示任务展开箭头、采样点嵌套子项或年月日历。

## 5. 保持不变的功能

地图点位点击仍进入 `TaskActivity`；任务详情页的距离校验、轨迹记录、二维码扫描、异常无水、拍照水印、记录落盘、WorkManager 上传和同步重试全部保持原实现。

## 6. 验证计划

1. 服务端单元/接口测试：迁移旧库、创建/同步任务、时间格式校验、已提交任务禁止改时间、设备名称返回。
2. 安卓编译与现有 smoke/security/schema/api/track 测试。
3. 手工回归：离线进入任务页、切换日期、打开采样点、开始前往、扫码、拍照、断网保存、恢复网络上传。

## 7. 地图多样本标记与长编号适配

- 安卓地图按 `site_id` 汇总当前可见任务；同一采样点只有一个任务时保持服务器下发的真实坐标。
- 同一采样点包含多个样本任务时，参照网页端算法，将各任务标记沿真实点位周围 28 米半径均匀展开，避免完全重叠；点击每个标记仍进入其对应的采样任务详情。
- 历史序号继续绘制在水滴图标内；对 `12.13` 等较长编号，根据实际文字测量宽度自动缩小字号，避免文字被水滴边缘遮挡或裁切。
- 标记分组和字号适配使用独立、无 Android UI 依赖的计算逻辑，并通过单元测试覆盖三样本展开、单样本不偏移和小数编号完整显示。

## 8. 采样点详情紧凑化

- 详情页移除风险提醒卡片；定位卡片仅隐藏 WGS84 坐标文字，距离、精度和 300 米硬限制继续保留。
- 管理员说明区域只显示点位备注；有参考图片时在上方显示图片，没有图片时不保留空白图片区。
- 已采样任务进入只读详情，保留采样时间、距离、精度、天气、异常说明、审核状态等信息，并显示用户采样照片。照片优先读取手机本地缓存，上传后使用服务器签名地址。
